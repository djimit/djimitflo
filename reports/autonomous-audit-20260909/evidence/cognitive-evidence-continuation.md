The measured defect was **false improvement without new outcomes**, not a lack of tests. Actual SQLite/service execution with ten fixed episodes (five failures, five successes) initially reported success fraction0.5/count10. The same immutable oracle after correction reports0.5/count10, absolute error0 and phantom replications0. ## Existing-boundary repair

- `CognitiveLoopClosureService` extracts current patterns from distinct durable loop rows, not an unpersisted five-item buffer. A recreated service can learn from fewer than five stored episodes. The later actual HTTP proof exposed stale current results at global batch boundaries; that batching was removed. Every new unique episode now refreshes the existing strategy/meta projections atomically.
- A completion replay or multiple event-bus listeners records one loop once. Historical duplicate rows are retained, but excluded from projected replication counts. No migration or historical deletion occurs.
- Strategy statistics replace the projection of the current distinct patterns; they do not add the same pattern on each call. IDs remain stable. Meta-learning counts distinct durable episodes rather than summing overlapping goal/strategy patterns.
- Current partial batches are reflected when evolution is explicitly requested. Revised imported lessons update action text without phantom application counts; downgraded advisory evidence no longer retains an old eligible high-effectiveness strategy.
- Observed loop outcomes carry `evidence_basis=recorded_outcomes`, `confidence_basis=sample_count_heuristic`, `causal_support=false`. Sender effectiveness remains `self_reported`; it is not blended into observed outcomes. Advice remains advice. New unobserved strategy use returns null rather than pretending the refresh timestamp was application; existing NOT NULL storage uses an explicit empty-string absence sentinel.
