## Observational economics, not causal swarm ranking

Thirty-day doc-drift cohort:

| Recorded topology | Completed / blocked / cancelled / failed | Completed mean elapsed / mean review leases |
|---|---|---|
| single maker |133/29/23/1 |468s /1.46 |
| multi maker |69/74/12/0 |1311s /4.03 |

Assignment to evolve siblings, task difficulty, model/runtime, retries, terminal status and censoring differ. Means use updated_at−created_at, not CPU/wall execution instrumentation. These numbers identify overhead worth investigating, **not evidence that multiple agents are worse**. no_maker completed rows can be operational bookkeeping or gym harnesses; don't count them as zero-cost successful agents. Manual runtime leases similarly require provenance rather than anthropomorphized agent counts.

Runtime failures have distinct causes: transport/provider, timeout, cancellation, reviewer verdict, missing changes and environment. Fleet signed reports lack independent skill artifact/evidence fields. Unknown model metadata is not proof an agent has no model. Deprecated capability rows may be deliberate retirement;34 candidate entries do not imply enabled capabilities.

Required crosswalk: existing native identity/service instance→registry identity→allowed capability and immutable version→selected runtime/model→lease/task→result authority→resource/outcome evidence. Attach existing identifiers at assignment rather than inferring relationships from matching names. Show enabled/available/last executed/last independently verified separately. Keep mock/manual/shadow scope visible.

A controlled comparison should hold task/model/tool access and total budget constant, randomize single versus existing maker+checker or sibling mechanism, independently score held-out tasks and track coordination/tool duplication, latency, cost and recovery. Do not remove mandatory safety/security checks to manufacture the simpler control. Protocol details and stopping constraints are in [18](18-controlled-experiments.md).
