Recommended contract, using current fields first:

| Boundary | Minimum evidence to retain |
|---|---|
| Discovery→candidate | origin event/proposal and evidence refs; task/failure class; producer instance/version |
| Candidate→artifact | skill/package ID, immutable content+script/manifest digest, parent version, expected task effect |
| Artifact→validation | existing admission result, frozen task/evaluator version, baseline/intervention outcomes and uncertainty |
| Validation→adoption | existing authorization, receiving runtime/adapter and installed digest; explicit disabled/rejected state |
| Adoption→execution | selected skill digest, task/run/agent/model/policy IDs, actual delivery vs assignment, tool/results |
| Execution→transfer/survival | independent comparable task outcome, cost/latency, later recheck/regression and decision record |

Start with one already existing reusable skill and two existing runtimes in an isolated environment, not bulk synchronization. Verify full artifact compatibility before executing, preserve least privilege and mandatory checks, and record non-adoption as a valid result.
