## Confirmed measurement-integrity defects

**Governance scale/cohort (P0).** GovernanceScorecardPage says 0–5 and colors≥4 green, but latest explainer-critic is 93.00. DB has 91 completed critic evaluations ranging 92.9–95.2. ExplainerGenerationService writes 0–100 critic scores into openmythos_eval_runs; getLeaderboard/getAgentScore returns latest raw values across completed agents and trends without benchmark comparability. Fix by cohort/scale metadata and filtering; never make a cross-task ranking valid merely by dividing by 20. Existing public getModelOnlyLeaderboard already excludes incompatible runs and should inform the authenticated fix. No downstream admission bypass was tested or alleged.

**Timestamp text mismatch (P0).** SelfHealingService compares ISO `...T...Z` strings to SQLite `datetime()` strings containing a space. Same-date lexical order differs from chronological order. At the retained snapshot, its 24 h source predicate counted 135 runs (128 completed/7 blocked); normalized julianday comparison counted 73 (70 completed/3 blocked). Stale predicate returned 0; normalized comparison returned 11. A later UI scan showed 136 total/0 stale (system continued running). An isolated SQLite in-memory assertion reproduced the same-day older-record omission. The normalized 11 are records meeting the detector's intended predicate; whether prepared leases should operationally expire at 1 h is a separate policy decision.

**Failure event taxonomy (P1).** OpenCode `step_finish reason=tool-calls` emits TASK_FAILED/ERROR. DB contains 6,722 such task.failed events and 90 historical log events. Terminal task outcome, model transport ok, tool progress and review error count are different units. Correct the writer and derived error counters; preserve raw history and annotate/recompute rather than silently erase audit events.

**Stall time origin (P1).** Memory-holdout experiment has stop_by 27Oct while audit clock 23Oct; target attainment already makes it overdue for a verdict. StallWatch uses stop_by as **since**, yielding future origin rendered “<1 h ago.” The target-reached alarm can be legitimate. Use target-reached/detection time for elapsed stall, retain future deadline separately; do not suppress the alert just because its stop date is future.

## Durable outcome and causal contract

Keep separate: discovery/proposal activity; goal/task/PR output; point-in-time gate verification; merge plus 14/30-day survival; independently reproduced capability improvement; randomized/credible causal effect. Current cockpit/evolution explicitly mark capability gain, reproduction and some survival windows unmeasured. Preserve UNKNOWN. Use existing experiment registry/protocol, treatment assignment, trial diagnostics, frozen artifact/model/config identity, eligible population and independent checker evidence. Where absent, show missing linkage/uncertainty rather than invent an effect size.

Minimum per-metric contract: definition/owner; entity unit; numerator/denominator; cohort key and exclusions; window/time-field; as-of/refresh; authoritative source/version; query status (ok/error/unknown); n and price/attribution coverage; actionable threshold; drill-down. Prefer a tooltip/details disclosure beside the value. Acceptance fixtures must include repeated panels, terminal archived refinements with historical goals, first gate failures vs true regressions, metadata-only updates, mixed timestamp formats,>12 work groups, missing tables and failed reads.
