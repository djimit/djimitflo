- Work in the existing OpenMythos and DjimitFlo pull-request branches.

## Execution loops

### L1 — governed change loop

`observation -> typed goal -> risk -> maker -> independent checker -> deterministic checks -> human gate -> canonical deploy -> outcome`

Exit only when correlation, artifact identity, tests, review metadata and outcome are complete. Deliberate denial and terminal failure are valid outcomes.

### L2 — research loop

`question -> preregistration -> calibrated challenge -> paired replications -> invariant/oracle analysis -> falsification -> finding -> intervention candidate`

Exploratory evidence cannot promote. A control floor or ceiling invalidates the confirmatory comparison and triggers recalibration instead of a positive claim.

### L3 — curiosity loop

`gap/dream -> deduplicate -> rank -> one bounded Paperclip-ready protocol -> evidence request -> research loop`

At most one new opportunity is exported per planning cycle. Every exported item carries a research question, null hypothesis, falsification criteria, budget, reversibility and `human_required=true`.

### L4 — recovery loop

`failure/denial -> evidence -> containment -> rollback or terminal rejection -> retest -> retained learning`

Recovery never rewrites the original failure. It appends a linked outcome.
