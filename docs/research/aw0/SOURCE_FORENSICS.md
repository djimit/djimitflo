## 8. Verified vs inferred: summary

- **Verified:** architecture, equations, mask topology, loss weights, configs, licences of code and of each frozen dependency, checkpoint byte size and revision, the hybrid gate logic, the annotation/coordinator protocol, the seed discipline of the authoring loops, the robotics-only scope of every result.
- **Divergent (paper ≠ repo at pin):** hybrid "without repair" vs default R1 repair; benchmark 50 vs 100 episodes; post-train schedules (20 epochs / 100k steps vs 100k / 15k); joint steps 4 vs 6 vs 10; code canvas 128 vs 64/124; memory described in the paper but off in config; stale comments on `sigma_reweight`.
- **Inferred:** checkpoint stored in bf16 (about 5 B tensors); full inference stack about 21 GB on disk; inference VRAM needs ≥16–24 GB, CUDA only.
- **Not verifiable from the release:** every reported success number (no post-trained checkpoints, logs or pretraining data); which decode env knobs and perception flags produced the tables; the licence status of the Cosmos-derived weights under a BSD-2 label.
- **Out of scope by design:** any claim about software agents. AW-0 has none. All transfer to DjimitFlo is by analogy and must be tested on our own data (EXPERIMENTS.md).
