## Summary by AW-0 stream

- **C (plan/skills):** extraction EXISTS, consumption PARTIAL (gym-only playbook gene), version binding MISSING. AW-0's lesson is about the *consumed, frozen, contract-checked* library, which we do not yet have.
- **Z (predicted next observation):** only marginal tabular predictors (EP posterior, per-source base rate) and proposal-level forecasts exist. **A per-lease, pre-maker outcome predictor is MISSING.** The substrate (judgment-service + local System One) and the scoring (forecastScoresV2) both EXIST.
- **A (action):** rule-based, event-driven, budget-bounded, governed by `EFFORT_FLOOR`. There is no predictive arbitration between operators.
- **Labels:** executed deterministic checks, checker verdicts and held-out Stryker/fresh-mutant kill are valid. "verified" is noisy (about 39–49 % environmental failures among non-verified). 14-d survival cannot fail.
