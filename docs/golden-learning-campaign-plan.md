# Golden Learning Campaign

Status: `VALIDATED_CANDIDATE_REVIEW_REQUIRED`  
Campaign: `djimit-golden-learning-20260907`  
Authority: OpenMythos specifies and evaluates; WorldLab generates longitudinal evidence; DjimitFlo mediates execution, approval and audit; EVE-V challenges evidence; Federation remains operational authority.

## Objective

Close one complete, falsifiable learning chain from observation to governed evolution while making every interaction, trade-off and evidence link visible in the existing Interaction Board. No new control plane, task engine, database, vector store, MCP server or agent identity is introduced.

## Success evidence

The campaign succeeds only when one stable correlation chain proves:

`observation -> question -> hypothesis -> control/treatment experiment -> independent reproduction -> causal outcome -> proposed intervention -> maker/checker validation -> OpenMythos and WorldLab retest -> human promotion decision -> measured operational outcome`

Required campaign evidence:

- one pointwise `PASS` plus trajectory `FAIL` from at least 30 paired control/treatment replications;
- explicit `PASS`, `FAIL` or `UNDETERMINED` at every assurance gate;
- an independent checker assessment with all seven identity dimensions known;
- a real operational outcome with candidate, capability, model, runtime, skill hash, baseline, metric, confidence and causal status;
- a tested containment, rollback or retirement path;
- one correlation identifier linking WorldLab evidence, DjimitFlo goal/change, review and retest;
- no aggregate World Score and no promotion from a single model opinion or trajectory.

## Ordered goals

### Wave 0 - P0 truth and learning spine

1. `GLC-01-source-provenance`: publish the clean candidate branch with exact commit, image digest, tests, rollback and `REVIEW_REQUIRED`; canonical merge stays a human decision.
2. `GLC-02-observation-learning-spine`: prove the existing WorldLab outcome event -> ingestion -> assessment -> inert goal -> interaction-ledger path end to end.
3. `GLC-03-curiosity-experiment`: convert a deduplicated curiosity gap into a preregistered, bounded research work item carrying question, null hypothesis, variables, controls, replication count, stopping condition and falsification criteria.

### Wave 1 - P0/P1 independent evidence

4. `GLC-04-causal-outcome-attribution`: reject promotion for correlated or exploratory evidence and preserve exact candidate, capability, model, runtime and skill attribution.
5. `GLC-05-reviewer-independence-routing`: select or block a checker using the existing seven-dimensional independence vector; different IDs alone are insufficient.
6. `GLC-06-contract-golden-traces`: attach at least one replayable success or deliberate-denial trace to every declared ecosystem contract; missing observations stay `UNDETERMINED`.

### Wave 2 - P1/P2 interaction and longitudinal proof

7. `GLC-07-interaction-board-actions`: add four typed, audited actions to an evidence card: request evidence, challenge claim, request reproduction and start experiment. Actions create existing hypotheses, discussions, decisions or work items; they never execute tools directly.
8. `GLC-08-outcome-specialization`: update specialization only from attributed lease outcomes and expose sample size and success rate; no self-declared specialization.
9. `GLC-09-worldlab-pointwise-trajectory-pov`: run the shared-memory injection control/treatment campaign with 30 paired replications and prove a valid pointwise `PASS` plus trajectory `FAIL` family.

### Wave 3 - P2/P3 recovery and lifecycle

10. `GLC-10-counterfactual-recovery`: replay a trajectory with an explicit intervention and test correction persistence and recovery without labelling temporal order as causality.
11. `GLC-11-skill-belief-retirement`: automatically contain repeatedly falsified capabilities and demote contradicted beliefs; release or reactivation requires WorldLab, OpenMythos and approval evidence.
12. `GLC-12-economics-federation-chaos`: only after goals 1-11, compare scarcity, provider monoculture, stale registry and recovery in the synthetic read-only federation mirror.

## Four reusable agent skills

These are bounded behaviours inside existing services, not new agent types:

- inquiry-to-experiment: turn a gap into a preregistered falsifiable protocol;
- independent-reproduction: reproduce evidence with independent model, provider, prompt, context, memory, retrieval and oracle metadata;
- causal-outcome-attribution: connect a candidate and exact skill/runtime identity to an operational delta;
- belief-and-skill-retirement: contain falsified capability and demote contradicted memory until independent release evidence exists.

## Execution and stop rules

- Execute goals in dependency order; a later wave cannot satisfy an unmet predecessor.
- Use deterministic or synthetic checks before paid or external model runs.
- Keep WorldLab network denied, credentials synthetic, tools simulated and production mutation unavailable by default.
- Every write outside the lab goes through existing DjimitFlo policy, ToolBroker, maker/checker and approval gates.
- A failed, missing or unknown proof is `FAIL` or `UNDETERMINED`, never implicit `PASS`.
- Stop and simplify if WorldLab cannot produce a reproducible pointwise `PASS` plus trajectory `FAIL` that static OpenMythos misses.
- P3 chaos work remains `NOT_STARTED` until the earlier causal and lifecycle gates pass.

## Removal strategy

The plan is data plus thin integrations over existing contracts. Remove the campaign batch, Interaction Board action controls and research projection method independently; existing goal, discussion, hypothesis, outcome, audit and WorldLab semantics remain intact.
